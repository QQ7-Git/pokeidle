<h1 align="center">🎮 PokéIdle</h1>

<p align="center"><strong>探索地區・收集寶可夢・打造你的最強隊伍</strong></p>
<p align="center">一款在瀏覽器中遊玩的寶可夢放置收集遊戲。</p>

本作品修改自 [jinwind1/pokemon-idle](https://github.com/jinwind1/pokemon-idle)，原專案作者為 **jinwind**。此版本已修改遊戲介面、功能與資料，並非原作者發布的原版。

---

## 🚀 開始冒險

**線上遊玩：** [https://qq7-git.github.io/pokeidle/](https://qq7-git.github.io/pokeidle/)

下載專案後，以瀏覽器開啟 **`index.html`** 即可遊玩，無須安裝套件或建置。首次進入時可查看遊戲指引與免責聲明。

```text
選擇道路  →  自動戰鬥  →  收集寶可夢  →  培養隊伍  →  解鎖新地區
```

戰鬥自動進行；你可以自由查看地圖、調整隊伍與規劃培育方向。部分功能需達成地區圖鑑條件後解鎖。

## 🎮 遊戲系統

| 系統 | 玩法 |
| :--- | :--- |
| ⚔️ **自動戰鬥** | 探索道路、獲取經驗與金幣，並可依敵人選擇適合的隊員出戰。 |
| 📖 **寶可夢圖鑑** | 搜尋、篩選與管理收集成果，追求閃光與 6V 個體。 |
| 🏅 **徽章與寶石** | 完成地區圖鑑取得徽章，鑲嵌與合成寶石強化隊伍。 |
| 🌱 **樹果花園** | 種植、採收與餵食樹果，提升寶可夢的種族值。 |
| ⚡ **技能與天賦** | 手動升級技能、分配天賦點，發展不同的成長方向。 |
| 🗼 **極限對戰塔** | 挑戰高難度樓層，以歷史通關層數提升經驗、金幣與閃光機率。 |
| 🎯 **自由狩獵場** | 完成 Mega 圖鑑後，自選六隻寶可夢狩獵 6V 與閃光。 |

### 隊伍策略

隊伍最多編入 **6 隻**寶可夢。點選隊員可查看詳細數值與屬性來源；隊友與圖鑑中未上場的已捕獲寶可夢也會提供戰鬥加成。

推薦隊伍提供「現在最強」與「未來潛力」，確認後才會套用。未來潛力以最高等級的 5 倍（不超過上限）模擬滿級技能與進化形態，包含尚未擁有的進化，並比較候選隊伍的道路戰鬥時間及粗略倒下風險。圖鑑加成只計已擁有的寶可夢；套用時只使用已擁有的形態，實際戰力可能低於模擬。搜尋並非窮舉，也不預測養成時間。

### 極限對戰塔

每層需要連續擊敗六隻敵人；隊員各自保留血量，換人及接續下一隻敵人時不回復，全隊倒下才失敗。失敗、撤退或重新整理後，重新挑戰會從該層第一隻敵人開始。

敵人為 6V、技能滿級且樹果吃滿。我方圖鑑、天賦與寶石加成會隨樓層逐漸生效：第 1 層分別使用原本加成的 30%、25%、25%，第 255 層恢復至 100%。

可重複挑戰已通關的最高層，每次重新抽取敵人；通關、失敗或撤退均不影響原本的挑戰進度與最高紀錄。

### 自由狩獵場

完成 Mega 圖鑑後開放，須選擇六隻不同的寶可夢：傳說或幻之 1 隻、準神 2 隻、其他 3 隻。一般進化鏈僅可選基礎形態；Mega 形態算準神，傳說／幻之 Mega 則算傳說／幻之。

出現率固定為傳說／幻之 5%、準神各 10%、其他各 25%，不套用已完成寶可夢的徽章權重調整。單項 V 與閃光機率各為一般野外的 70%；敵人等級依所有已擁有寶可夢的最高等級決定。

## 🌙 離線進度

離開遊戲後，符合條件的離線時間會在返回時結算。結算完成可查看戰鬥、收穫、隊伍成長、重要事件及目前狀態。實際可結算時間依遊戲進度與徽章效果而定。自由狩獵場在網頁關閉期間不進行離線戰鬥結算。

> 不同瀏覽器、裝置與網址各自保存遊戲進度；線上版本不會自動同步本機存檔。

## 💾 存檔與備份

進度保存在目前瀏覽器的本機儲存空間。更換瀏覽器或裝置、清除瀏覽器資料之前，請到 **設定 → 存檔管理** 匯出備份。

> [!IMPORTANT]
> 匯入存檔會取代目前進度，請先備份。存檔雖經壓縮與編碼，**並未加密**，請妥善保存，不要公開分享。

支援文字及檔案匯入／匯出，並可讀取相容的舊版存檔。
